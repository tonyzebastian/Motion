# Procedural still

Read [the shared workflow](../../../docs/procedural-workflow.md). Use `remotion-render` for still export; use `riso-canvas` and its craft notes only for the four-ink Canvas look.

1. Establish the subject, feeling, format, output dimensions and exclusions. For an unfamiliar recognisable subject, inspect references that resolve form, pose, material and viewpoint. If asked for options, compare different compositions; otherwise choose and build.
   When the user asks for an image generated entirely with code, treat reference photos as visual guides only. Draw the scene with authored geometry, marks, and deterministic procedures; do not load, sample, trace automatically, recolor, or overlay the photo in the render. A palette mapping or texture pass over source pixels is a photo treatment, not a code-generated recreation. If likeness is important, draft and inspect the subject's silhouette and key features as drawn shapes.
2. For ambitious work, prove a difficult focal area or representative full-size frame before elaborating the whole picture. Resolve silhouette, perspective, attachments and light before adding texture. A local edit needs only the relevant check.
3. Render the composition to a native-resolution PNG with Remotion's still command. Inspect the whole image at viewing size and the difficult areas at 1:1. Do not present CSS scaling or enlarged screenshots as higher-resolution artwork.
4. For a substantial piece, keep `ARTWORK.md` beside the composition with the brief, observed references, size, composition decisions, inspected output and remaining weakness. Confirm the exported PNG's actual dimensions.

A still does not need an artificial animation loop or film timeline.
