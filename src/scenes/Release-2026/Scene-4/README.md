# Release 2026 — Scene 4

Scene 4 is a 1920×1080, 60fps, eight-second question dial.

- The AI icon enters from the left and reveals the first question.
- Surrounding questions fan into a 4° circular layout.
- The dial advances three times with anticipation, minimal overshoot, and a
  subtle icon pulse.
- The shared Release 2026 dither shader provides the animated background.

Edit question copy, icon source, and background values in the inline
`Scene-4` defaults in `src/Root.tsx`.

Preview with `npm run dev` or render a check using
`npx remotion still Scene-4 --frame=180`.
